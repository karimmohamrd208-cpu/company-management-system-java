# Company Management System (Java)

A desktop company management system developed in Java with Swing/JFrames and SQL database integration via JDBC (`mssql-jdbc`).

## Project Type & Contribution
- **Team Project:** Built as a collaborative team project for the Advanced Software Engineering course, contributing to application modules, UI forms, and integration.

## Tech Stack
- Java, Swing (JFrames), SQL Server / JDBC

## Project Structure
- `src/`: Java source files, models, and JFrame forms.
- `nbproject/`: NetBeans project configuration.
- `database.sql`: Database schema and setup script.
