# Company Management System (Java Swing / JFrames)

A desktop company management system developed in Java as a team project for the Advanced Software Engineering course, featuring GUI screens built with JFrames and SQL database integration.

## Key Features
- **Desktop GUI (JFrames):** Interactive screens for validation, core operations, table queries, company modules, and summary views.
- **Database Integration:** Connected via JDBC (`mssql-jdbc`) with a SQL setup script (`database.sql`).

## Project Structure
- `src/`: Java source code and JFrame UI forms.
- `nbproject/`: NetBeans project configuration.
- `database.sql`: SQL script for database setup.
